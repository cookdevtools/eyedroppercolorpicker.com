Help

Everything about the Eye Dropper Color Picker extension.

Basics

How do I pick a color?

Click the extension icon (or press Alt+C), then press Space (or Enter) or click Pick color. A magnifier follows your cursor — click any pixel on the screen. The color appears in the popup and its code is copied to the clipboard.

Can I pick a color outside the browser?

Yes. The eyedropper works over the whole screen, including other windows and apps, as long as the popup stays open.

How do I pick several colors quickly?

After each pick the Pick color button keeps keyboard focus, so just press Space again. Every pick is saved under Recent. For a run of picks without leaving the page, use the Precision picker with Shift+click (see below).

Why doesn't the shortcut start picking right away?

Browsers only allow the eyedropper to open after a click or key press inside the extension window. Alt+C opens the popup; Space starts picking — two keys, no mouse needed.

What is the Precision picker?

Click Precision next to Pick color, or press Shift+Space. The page freezes as a snapshot, a crosshair follows your mouse and a large magnifier sits beside it, so it never hides the spot you are aiming at. Arrow keys move exactly one physical pixel (Shift+arrow: ten), the mouse wheel changes how many pixels the magnifier shows, Space or a click copies the color and returns you to the popup, Esc goes back without picking. It works on normal web pages; on Chrome's own pages, the Web Store and PDFs use the regular picker.

Can I pick several colors in a row with Precision?

Yes — Shift+click (or Shift+Space) picks the color and keeps the magnifier open; the colors you have taken are listed under it. Press Esc when you are done: all of them are in Recent, and Undo in the popup removes the whole run.

Can I move the regular magnifier pixel by pixel?

While Chrome's magnifier is open, the arrow keys nudge it by one CSS pixel — on displays scaled to 125–150% that is about 1.5 physical pixels. For true 1-pixel steps use the Precision picker.

How do I copy several colors at once?

Ctrl+click (or Cmd+click) colors in Recent or Palette to select them, Shift+click to select a range, then use Copy in the bar that appears (or Ctrl+C). Copy all copies the whole list, one color per line, in the format you have selected.

I picked the wrong pixel

Click Undo in the message that appears after a pick, or press Esc or Ctrl+Z while that message is visible. The previous color comes back and the wrong one is removed from Recent. You can also remove any color: right-click it and choose Remove, or click it and press Delete, or select several with Ctrl+click and press Delete. Every removal, including Clear, offers Undo.

What does right-click do?

Right-click any color in Recent or Palette for a small menu: Copy, Select, Pin to palette (or Remove from palette) and Remove.

Why is there a short pause before the magnifier appears?

The magnifier is Chrome's built-in eyedropper. Before it opens, the browser takes a snapshot of your screen, which takes up to about a second on large or scaled displays. The pause happens on every pick (Space → wait → click), and the extension cannot speed it up. The Precision picker snapshots the tab once and then lets you pick instantly, including several colors in a row.

Can I fine-tune a color?

Click the big color square: an editor opens with a saturation/brightness field and a hue bar, with the marker on your current color. Drag the markers or type a HEX value, then Use makes it the current color (and adds it to Recent, with Undo), Copy copies it. While the editor is open, clicking any color in Recent or Palette loads it into the editor.

Dark or light theme?

The popup follows your system theme. Click the sun/moon icon in the header to switch; the choice is remembered and synced with your other devices.

Can I move the picker window?

The popup is attached to the toolbar, but you can click the “open in a window” icon in its header to get the same picker in a small separate window that you can drag anywhere and keep on top while you work.

How do I change the shortcut?

Open chrome://extensions/shortcuts and set any combination for “Open Eye Dropper Color Picker”. Note that on some keyboard layouts the right Alt key acts as AltGr and is not recognized — use the left Alt.

Formats, history, palette

Which formats are available?

HEX (#1A73E8), RGB (rgb(26, 115, 232)), HSL, HSB (as in Figma and Photoshop, also called HSV), the nearest Tailwind CSS color class and a CSS custom property (--color: #1A73E8;). Click a tab to switch; the selected format is what gets copied.

What does “≈ Royal Blue” mean?

It's the closest named color (from the CSS color names). The ≈ sign means it's an approximation, not an exact match. You can turn names off in Settings.

How do the palette and export work?

Hover a color in Recent and click + to pin it to the Palette, right-click it and choose Pin to palette, or simply drag it there. The palette holds up to 48 colors; drag to reorder them. Export copies the palette as CSS variables, JSON or a plain list, Copy all copies one color per line.

Where is my data stored?

Only in your Chrome profile (chrome.storage.sync). Nothing is sent to us. See the privacy policy.

Troubleshooting

The magnifier doesn't appear

Make sure you're on Chrome 95 or newer (or another Chromium browser such as Edge or Brave). On Linux, some window managers don't support the system eyedropper; try picking from inside the browser window.

The code isn't copied

Check Settings → Copy automatically after picking. You can always copy manually by clicking the code, the swatch or the copy icon.
