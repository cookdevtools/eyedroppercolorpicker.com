Help

Everything about the Eye Dropper Color Picker extension.

Basics

How do I pick a color?

Click the extension icon (or press Alt+C), then press Enter or click Pick color. A magnifier follows your cursor — click any pixel on the screen. The color appears in the popup and its code is copied to the clipboard.

Can I pick a color outside the browser?

Yes. The eyedropper works over the whole screen, including other windows and apps, as long as the popup stays open.

How do I pick several colors quickly?

After each pick the Pick color button keeps keyboard focus, so just press Enter (or Space) again. Every pick is saved under Recent.

Why doesn't the shortcut start picking right away?

Browsers only allow the eyedropper to open after a click or key press inside the extension window. Alt+C opens the popup; Enter starts picking — two keys, no mouse needed.

How do I change the shortcut?

Open chrome://extensions/shortcuts and set any combination for “Open Eye Dropper Color Picker”. Note that on some keyboard layouts the right Alt key acts as AltGr and is not recognized — use the left Alt.

Formats, history, palette

Which formats are available?

HEX (#1A73E8), RGB (rgb(26, 115, 232)), HSL, HSB (as in Figma and Photoshop, also called HSV), the nearest Tailwind CSS color class and a CSS custom property (--color: #1A73E8;). Click a tab to switch; the selected format is what gets copied.

What does “≈ Royal Blue” mean?

It's the closest named color (from the CSS color names). The ≈ sign means it's an approximation, not an exact match. You can turn names off in Settings.

How do the palette and export work?

Hover a color in Recent and click + to pin it to the Palette (up to 12). Export copies the palette as CSS variables, JSON or a plain list.

Where is my data stored?

Only in your Chrome profile (chrome.storage.sync). Nothing is sent to us. See the privacy policy.

Troubleshooting

The magnifier doesn't appear

Make sure you're on Chrome 95 or newer (or another Chromium browser such as Edge or Brave). On Linux, some window managers don't support the system eyedropper; try picking from inside the browser window.

The code isn't copied

Check Settings → Copy automatically after picking. You can always copy manually by clicking the code, the swatch or the copy icon.
